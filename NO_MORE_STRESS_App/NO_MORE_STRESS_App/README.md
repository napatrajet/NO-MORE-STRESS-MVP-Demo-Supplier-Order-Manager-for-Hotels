# NO MORE STRESS — Supplier Order Manager for Hotels (MVP Prototype)

แพลตฟอร์มเว็บแอปพลิเคชันสำหรับใช้งานบน **iPad, โทรศัพท์มือถือ และคอมพิวเตอร์** ออกแบบมาเพื่อช่วย Supplier รวบรวมออเดอร์จากโรงแรมที่ส่งมาทาง **LINE** และ **Gmail** (ทั้งรูปภาพ ไฟล์ PDF และข้อความ) พร้อมคัดแยกตามวันที่จัดส่งล่วงหน้าและรวมน้ำหนักสินค้าส่งต่อไปยังร้านค้าส่งอัตโนมัติ

## โครงสร้างไฟล์ในโฟลเดอร์
- `index.html` — หน้าโครงสร้างหลักของแอปพลิเคชัน (รองรับการเปิดผ่าน Safari / Chrome บน iPad และมือถือ)
- `styles.css` — ไฟล์ตกแต่งธีมสีกรมท่า-ขาวสไตล์มินิมอล และระบบ Responsive Layout
- `app.js` — ระบบจัดการข้อมูลออเดอร์ การรวมน้ำหนักสินค้า การสลับวันที่จัดส่ง และตัวจำลองการอ่านข้อความออเดอร์
- `README.md` — คู่มือการใช้งานไฟล์

## วิธีเปิดใช้งาน
1. **แตกไฟล์ (Unzip)** โฟลเดอร์ `NO_MORE_STRESS_App.zip` ออกมาไว้ในเครื่องหรือในแอป Files ของ iPad / iPhone
2. กดเปิดไฟล์ **`index.html`** ด้วยเบราว์เซอร์ (Safari, Chrome หรือ Edge)
3. *(แนะนำสำหรับทดลองใช้งานจริง)* สามารถนำโฟลเดอร์นี้ไปอัปโหลดขึ้น **Netlify Drop**, **Vercel** หรือ **GitHub Pages** เพื่อสร้างเป็นลิงก์ URL สำหรับส่งให้ลูกค้าโรงแรมหรือ Supplier ทดลองกดใช้งานผ่านมือถือได้ทันที

## ฟีเจอร์หลักภายในตัวต้นแบบ
1. **Home (หน้าหลัก):** แสดงจำนวนโรงแรม ออเดอร์ น้ำหนักรวม (kg) แยกสถานะระหว่าง **รายการใหม่จากโรงแรม** กับ **รายการที่ส่งสั่งซื้อร้านค้าแล้ว** และกดดูหลักฐานต้นฉบับจาก LINE/Gmail ได้
2. **Orders (รายการทั้งหมด):** กรองดูเฉพาะรายการเข้าใหม่หรือรายการที่สั่งร้านค้าแล้ว
3. **PO (ตั้งค่าการเชื่อมต่อ):** เปิด-ปิดการอนุญาตเข้าถึง Gmail / LINE, เลือกเชื่อมต่อร้านค้าผู้จัดจำหน่าย และทดลองวางข้อความออเดอร์เพื่อแปลงเข้าระบบทันที
4. **Schedule (ตารางวันจัดส่ง):** คัดแยกออเดอร์ที่โรงแรมส่งล่วงหน้าตามวันที่จัดส่ง (`17 Aug`, `18 Aug` ฯลฯ)
5. **Shopping (ใบสรุปซื้อของรวม):** รวมน้ำหนักสินค้าแต่ละชนิดของทุกโรงแรมในวันจัดส่งนั้นๆ พร้อมกดส่งใบสั่งซื้อไปยังร้านค้าส่งในคลิกเดียว
6. **Checklist (เช็กลิสต์จัดของ):** ติ๊กตรวจสอบรายการสินค้าที่จัดเตรียมเสร็จแล้วแยกตามแต่ละโรงแรม
